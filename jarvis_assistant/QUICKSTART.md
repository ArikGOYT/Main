# 🚀 Быстрый старт с JARVIS

## 1. Установка зависимостей

```bash
# Создание виртуального окружения
python -m venv venv

# Активация (Linux/Mac)
source venv/bin/activate

# Активация (Windows)
venv\Scripts\activate

# Установка пакетов
pip install -r requirements.txt
```

### ⚠️ Важно для Linux

Для работы с микрофоном может потребоваться установка системных пакетов:

```bash
# Ubuntu/Debian
sudo apt-get install python3-pyaudio portaudio19-dev

# Fedora
sudo dnf install portaudio-devel python3-pyaudio

# Arch
sudo pacman -S portaudio pyaudio
```

## 2. Настройка API ключей (опционально)

Для полной функциональности с ИИ:

```bash
cp .env.example .env
```

Откройте `.env` и добавьте ваш ключ:

```
OPENAI_API_KEY=sk-your-key-here
```

Получить ключ можно на: https://platform.openai.com/api-keys

**Без ключа** ассистент будет работать в базовом режиме с ограниченными возможностями.

## 3. Запуск

```bash
python main.py
```

## 4. Использование

### Голосовой режим (с микрофоном)

1. Скажите слово активации: **"Джарвис"**
2. Дождитесь ответа "Да, сэр? Слушаю внимательно"
3. Произнесите команду
4. Скажите "отбой" или "пока" для выхода из режима активации

### Текстовый режим (без микрофона)

Ассистент автоматически запустится в текстовом режиме если микрофон недоступен.

Просто вводите команды:
```
Вы: привет
Вы: который час
Вы: расскажи анекдот
Вы: выход
```

## 5. Доступные команды

- **Время** - показать текущее время
- **Дата** - показать дату  
- **Погода** - узнать погоду (требует настройки API)
- **Система** - информация о компьютере
- **Помощь** - список команд
- **Стоп/Выход** - завершить работу

Также можно задавать любые вопросы (при наличии API ключа).

## 🔧 Решение проблем

### Микрофон не работает
- Проверьте права доступа к микрофону в системе
- Установите `portaudio` и `pyaudio` (см. выше)
- Используйте текстовый режим

### Ошибка синтеза речи
- Проверьте подключение к интернету (для gTTS)
- Офлайн режим (pyttsx3) должен работать без интернета

### Медленная работа
- Используйте офлайн TTS (включен по умолчанию)
- Отключите контекст диалога в настройках
