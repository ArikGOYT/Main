# JARVIS-like AI Assistant

Персональный ИИ-ассистент с голосовым управлением, вдохновленный Джарвисом из Железного Человека.

## Возможности

- 🎤 **Голосовое распознавание** - понимание команд через микрофон
- 🔊 **Голосовой синтез** - озвучивание ответов (TTS)
- 🧠 **Интеграция с LLM** - умные ответы через OpenAI/Gemini/локальные модели
- ⏰ **Напоминания и таймеры** - управление временем
- 🌐 **Поиск в интернете** - получение актуальной информации
- 💻 **Управление системой** - базовые команды ОС
- 📅 **Календарь и погода** - интеграция с внешними API
- 🏠 **Умный дом** (опционально) - управление устройствами

## Структура проекта

```
jarvis_assistant/
├── main.py              # Точка входа
├── config/
│   └── settings.py      # Конфигурация
├── modules/
│   ├── speech.py        # Распознавание и синтез речи
│   ├── brain.py         # Интеграция с ИИ-моделью
│   ├── commands.py      # Обработка команд
│   ├── weather.py       # Погодный модуль
│   └── reminders.py     # Напоминания
└── assets/              # Звуковые эффекты, темы
```

## Установка

### 1. Создание виртуального окружения

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка

Скопируйте `.env.example` в `.env` и заполните ключи API:

```bash
cp .env.example .env
```

## Быстрый старт

```bash
python main.py
```

## Требования

- Python 3.8+
- Микрофон
- (Опционально) Ключи API для расширенных функций

## Расширение функционала

Вы можете добавлять собственные модули в папку `modules/`:

```python
# modules/my_module.py
from modules.base import BaseModule

class MyModule(BaseModule):
    def execute(self, command):
        # Ваша логика
        pass
```
